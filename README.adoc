= Helserefusjon - åpne data
:toc:
HTTP API med åpne data fra Helserefusjonsområdet. APIet leverer data på JSON og XML format.

== Om APIet
Det tilbys API for følgende områder:

* Aggregert takstbruk
* Bandasjister med direkte oppgjørsavtale
* Takstkoder
* Laboratoriekodeverk (NLK-koder)
* Refusjonskategorier for NLK, NCRP og patologi
* Apat-kombinasjoner


Lisens for offentlige data https://data.norge.no/nlod/no

Se også https://ehelse.no/takster

=== Ny rot-URL
APIet var tidligere kun tilgjengelig på https://helserefusjoner-kuhr.nav.no. Denne vil på sikt bli faset ut.
Ny rot URL er https://opne-data-api.helserefusjon.no. Det er også gjort en endring i pathene på URLene.
De gamle URLene vil fortsette å fungere inntil ingen bruker de lenger.

=== OpenAPI-spesifikasjon
link:openapi.yaml[openapi.yaml] beskriver APIet i OpenAPI 3.1-format, og kan åpnes i f.eks. Swagger UI eller brukes til å generere klientkode.
Spesifikasjonen sjekkes mot svar fra APIet ved hver endring i repoet.

=== Daglige øyeblikksbilder
Mappen link:data[data] inneholder en kopi av kodeverkene (takstkoder, NLK-koder, refusjonskategorisatser, Apat-kombinasjoner, fagområder og bandasjister).
Kopien oppdateres hver natt av link:.github/workflows/snapshot.yml[en GitHub Action], og git-historikken viser dermed hva som er endret og når.

Filene er i JSON Lines-format (én oppføring per linje), sortert på id. I `nlkkoder.jsonl` er feltet `refusjonskategorisats` fjernet, siden satsene finnes i `refusjonskategorisatser.jsonl`.

Kjør lokalt:

[source,sh]
----
pip install -r scripts/requirements.txt
python scripts/snapshot.py --out data --validate
----

| redusert_repetisjonsprosent |
| spesialisttakst | `true` eller `false` (som tekst)

Felt uten verdi er utelatt fra svaret.


=== Parametre

|===
| Parameter | Beskrivelse

| HTTP Header: Accept| Angir hvilket format data skal leveres på. Støtter application/xml og application/json
| Query: fagomraade | Fagområdekode, se <<Fagområder>>
| Query: gyldigdato | Filtrerer takstene til kun de som er gyldige på en gitt dato. Dato på formatet `yyyy-MM-dd`
| Query: takstkode | Filtrer takstene til en gitt kode, kan kombineres med de andre parametrene eller brukes alene.
| Query: beskrivelse | Filtrer på beskrivelsen til takstkoden, kan kombineres med de andre parametrene eller brukes alene.
| Query: offisielle_ugyldige_takstkombinasjoner | Filtrer offisielle ugyldige takstkombinasjoner definert i feltet ugyldig_kombinasjon. Om alt filtreres så endres 'Alle unntatt' til 'Alle'. Mulige parametre: ja/nei.
|===
For query på takstkode og beskrivelse kan `%25` (URL-kodet `%`) brukes som jokertegn. F.eks. `%25undersøkelse%25` for å søke på alt som inneholder «undersøkelse».

=== Eksempel
https://opne-data-api.helserefusjon.no/v1/takstkoder?gyldigdato=2026-11-01&takstkode=2ad

== Aggregert takstbruk
APIet tilbyr statistikk over takstbruk for kommuner, fylker og hele landet, fordelt på år, måned, fagområder og praksistyper. Den geografiske inndelingen
er basert på behandlers adresse. For kommune/år er tallene begrenset til takster der antallet er større enn 5. For kommune/måned er tallene
begrenset til kommuner med over 10 000 innbyggere.

Dataene kan hentes som JSON eller XML, som CSV eller som Excel. Hvert format har sin egen URL.

=== URLer

URLene er satt sammen av et prefiks for formatet, et geografisk nivå og en periode:

----
https://opne-data-api.helserefusjon.no/v1/takstbruk/<format>/agtakst/<nivå>/<periode>
----

|===
| Del | Verdier

| `<format>` | Utelates for JSON eller XML (`.../takstbruk/agtakst/...`), `eksport` for CSV, `eksport/msexcel` for Excel
| `<nivå>` | `kommune`, `fylke` eller `landet`
| `<periode>` | `maned` eller `ar`
|===

Det gir 18 URLer, for eksempel:

|===
| URL | Resultatformat

| https://opne-data-api.helserefusjon.no/v1/takstbruk/agtakst/kommune/maned | JSON eller XML
| https://opne-data-api.helserefusjon.no/v1/takstbruk/eksport/agtakst/kommune/maned | CSV
| https://opne-data-api.helserefusjon.no/v1/takstbruk/eksport/msexcel/agtakst/kommune/maned | Excel
|===

CSV-filen er semikolonseparert og har en overskriftslinje.

=== Datainnhold

|===
| Felt | Beskrivelse

| ar | År
| maned | Måned (`01`–`12`). Bare for periode `maned`.
| takstkode |
| fagomraade | Fagområdekode, se <<Fagområder>>
| praksis_type_kode | Praksistypekode, se <<Praksistyper>>
| samhandler_praksis_type | Navn på praksistypen. Heter `praksis_type_navn` i CSV.
| behandler_kommunenr | Bare for nivå `kommune`
| behandler_fylke | Bare for nivå `fylke`
| antall_regninger |
| sum_antall_takst |
| sum_refusjon |
| sum_egenandel_betalt_av_pasient |
| sum_egenandel_dekket_av_folketrygden |
|===

=== Parametre

|===
| Parameter | Gjelder for | Beskrivelse

| HTTP Header: Accept | JSON/XML | Angir hvilket format data skal leveres på. Støtter application/xml og application/json
| Query: fagomraade | Alle | Obligatorisk. Kommaseparerte verdier, se <<Fagområder>>
| Query: fommaned | Periode `maned` | Obligatorisk. Første måned på formatet `yyyyMM`. Perioden kan ikke være lengre enn 13 måneder
| Query: tommaned | Periode `maned` | Obligatorisk. Siste måned på formatet `yyyyMM`
| Query: fomar | Periode `ar` | Obligatorisk. Første år på formatet `yyyy`
| Query: tomar | Periode `ar` | Obligatorisk. Siste år på formatet `yyyy`
| Query: takstkoder | Alle | Kommaseparerte verdier, se <<Takstkoder>>
| Query: kommuner | Nivå `kommune` | Kommaseparerte verdier, se <<Kommunenummer>>
| Query: fylker | Nivå `fylke` | Kommaseparerte verdier, se <<Fylkesnummer>>
| Query: praksistyper | Alle | Kommaseparerte verdier, se <<Praksistyper>>
|===

Mangler et obligatorisk parameter, svarer APIet med `400`. Ugyldige verdier, for eksempel en periode over 13 måneder,
gir ingen feilmelding, men et tomt svar (`{}` for JSON, bare overskriftslinjen for CSV).

== Bandasjister med direkte oppgjørsavtale

| gyldig_til |
